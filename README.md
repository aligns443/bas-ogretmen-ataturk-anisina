Cumhuriyet Bayramı için hazırlanmış bir C# konsol uygulaması. Çalıştırınca terminalde
önce **Atatürk portresini**, hemen altında da **içi Atatürk'ün bakışlarıyla dolu bir
Türkiye haritasını** çizer. En altta "Yurtta sulh, cihanda sulh." sözü yer alır.



# Kaynak koddan çalıştırma

Gereksinimler: **Windows** ve [.NET 10 SDK](https://dotnet.microsoft.com/download)

```bash
git clone https://github.com/aligns443/bas-ogretmen-ataturk-anisina
cd Atam
dotnet run
```




## İpuçları

- **Windows Terminal** önerilir. Klasik konsolda da çalışması için uygulama ANSI modunu kendisi açar.
- Yazı tipini küçült (`Ctrl` + fare tekerleği) ve pencereyi genişlet, görüntü çok daha net olur.
  Cascadia Mono ya da Consolas iyi sonuç verir.
- Pencere dar olursa görüntü otomatik küçülür. İstersen `--genislik` ile elle ayarlayabilirsin.
